**The Plan**
How do archaeologists share data? FAIR / CARE/ OCAP. 

**Skill Building**
- download data programmatically from the Archaeology Data Service ([here's some help](../assets/ads).)
- Find an interesting project at [OpenContext.org](https://opencontext.org/projects-index/). Follow your interest until you've got a dataset you'd like to explore. Use OpenContext's built-in data export features to get the data. Then make a new Google Colab notebook to explore the data using anything you've learned so far in the course (or, if you decide to continue with last week's theme, use the data to develop a game/playful approach). How do we observe the issues raised in the readings?
